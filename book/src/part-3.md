Part III is about abstraction: writing one piece of code that works at many
types. It covers parametric polymorphism and System F, the type inference that
lets Rust and Lean fill in most types for you, traits and type classes and the
dictionaries the compiler passes behind your back, and existential types, the
theory behind `impl Trait` and `dyn Trait`. Each of these is a feature you use
in Rust every day; each turns out to be a precise logical idea.
